##### POLAND NAVAL NAME LISTS (ISNE) #####
# Note: Vanilla HoI4 POL_ship_names.txt had these anomalies:
# 1. Light and heavy cruisers shared one 22-name list; battleships, battlecruisers and carriers shared one 13-name list.
# 2. Destroyers and cruisers mixed cities and battles with ship names; submarines held torpedo-boat names, "Kujawiak" four times.
# 3. Missing diacritics in the hull lists ("Wisla", "Gdansk", "Pilsudski", "Sokól", "Rys"); "Józef Piłsudzki"; "Podkapracie".
# 4. The Cities pool was a copy of the Regions pool; the battlecruiser fallback was "Krążownik" (cruiser).
# 5. The Kings and Historical Figures pools were bound to heavy and carrier hulls; they are universal here.
# Since 2026-11-17 this file replaces Jackhall's "Polish Ship Names" as well as vanilla's: only one of the two loads.
