##### ROMANIA NAVAL NAME LISTS (ISNE) #####
# Note: Vanilla HoI4 ROM_ship_names.txt had these anomalies:
# 1. Light and heavy cruisers shared one verbatim 10-name list; battleships and battlecruisers shared one 3-name list of cities.
# 2. Calqued fallbacks ("Crucisator Lumina" for light cruiser, "Vas de Razboi" for battleship) and no diacritics in the hull lists.
# 3. A Mexican city ("Puebla") and a duplicate ("Piatra Neamt") in the cities list; exonyms ("Dobruja", "Bukovina", "Budjak") in the regions list.
# 4. Destroyers carried the names of corvettes commissioned in the 1980s and 1990s; post-1945 place names ("Cluj Napoca", "Navodari").
# Romanian s-comma and t-comma are written with the cedilla forms, which the game fonts carry [SPR-023].
